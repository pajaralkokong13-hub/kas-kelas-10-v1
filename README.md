# 📘 Sistem Pencatatan Kas Kelas 10

Aplikasi web ringan berbasis HTML, CSS, dan JavaScript untuk mengelola pemasukan dan pengeluaran uang kas **Kelas 10** secara praktis, transparan, dan mudah dibagikan.

## ✨ Fitur Utama
* **Data Murid Terintegrasi:** Mencatat iuran untuk 11 murid dengan tarif standar **Rp3.000 / minggu**.
* **Manajemen Periode & Tanggal:** Dilengkapi pemilih bulan, tahun, serta kolom tanggal untuk setiap minggu penagihan.
* **Aksi Cepat & Filter:** Pencarian nama murid, filter status (*Lunas* / *Belum Lunas*), dan tombol centang cepat per baris.
* **Catatan Pengeluaran:** Mencatat riwayat pengeluaran kas berdasarkan tanggal, kategori, dan nominal dengan perhitungan sisa saldo otomatis.
* **Statistik & Poin Kedisiplinan:** Menampilkan persentase target kas dan peringkat murid paling rajin membayar.
* **Laporan WhatsApp Otomatis:** Mengirimkan rekap pemasukan, pengeluaran, dan sisa saldo langsung ke grup WhatsApp kelas dalam satu klik.
* **Penyimpanan Lokal & Backup:** Data tersimpan otomatis di browser (*Local Storage*) dan dilengkapi fitur salin kode *backup*.

## 🚀 Cara Penggunaan
1. Buka tautan website aplikasi (via GitHub Pages atau Netlify).
2. Pilih **Bulan** dan **Tahun** periode kas di bagian atas.
3. Centang kotak minggu pada nama murid yang sudah membayar iuran.
4. Catat setiap transaksi keluar pada tab **Pengeluaran**.
5. Klik tombol **Kirim WA** untuk membagikan rekap laporan ke grup kelas.

## 🛠️ Teknologi yang Digunakan
* HTML5
* CSS3 (Responsive Design)
* Vanilla JavaScript (Local Storage API)
